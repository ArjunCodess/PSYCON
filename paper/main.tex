\begin{abstract}
This paper presents Psycon, a prototype multimodal wearable system for estimating psychological state from physiological, motion, and audio-derived signals. The initial software and machine learning pipeline is validated using the public WESAD dataset before adaptation to data collected from Psycon hardware, pending IRB guidance.
\end{abstract}

\section{Introduction}

Stress detection using wearable sensors is challenging because individual signals can be noisy and ambiguous. Psycon explores whether multimodal sensing can improve robustness compared with single-modality approaches.

\section{Methods}

The planned system combines a wrist biosensing module, an ear audio module, and a mobile application for synchronization, feature extraction, inference, visualization, and local storage. Initial experiments use WESAD for software pipeline validation.

\section{Results}

Results will include baseline performance, classical machine learning performance, and comparisons between single-modality and multimodal fusion models.

\section{Discussion}

The discussion will cover model performance, sensor limitations, privacy considerations, and the transition from public-dataset validation to Psycon hardware validation.
