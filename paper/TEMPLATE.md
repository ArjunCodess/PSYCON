# Preprint template attribution

The paper and synopsis use the `article` class and `arxiv` style in the requested template:

https://www.overleaf.com/latex/templates/style-and-template-for-preprints-arxiv-bio-arxiv/pkzcrhzcdxmc

Overleaf credits zixuan lu and lists the template page under CC BY 4.0. The reusable style file is from George Kour's upstream https://github.com/kourgeorge/arxiv-style and is distributed under the MIT license, preserved in `arxiv-LICENSE.txt`.

Project-specific changes are the manuscript content, authors, running title, and working-draft label. The separate synopsis uses the same typography and page geometry, with a deliberate page break. No example research or sample references from the template remain.
