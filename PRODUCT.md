# PSYCON product context

## Register

Product. These pages are working tools for the private communication pilot and the existing research workflow.

## People and purpose

Wearers enroll, upload conversations, review evidence, and practice communication goals. Researchers review group recordings and human marksheets. Operators inspect device sessions and processing jobs. The start page connects these workspaces.

## Design principles

Keep the existing Flask, Jinja, HTML, CSS, and JavaScript stack. All workspaces use the same visual language and navigation. Use the research console's paper background, teal actions, restrained borders, and readable type. Explain tasks in plain language and keep the start page brief.

Preserve keyboard access, visible focus, mobile layouts, and reduced-motion support. Status and errors must use text as well as color. Avoid decorative effects or separate themes that make the tools feel unrelated.
