\section{Calibration Summary}
\label{sec:calibration-summary}

For each sensor, the following should be documented:
\begin{itemize}
    \item Calibration date
    \item Firmware version
    \item Environmental conditions
    \item Test operator
    \item Calibration method
    \item Results
\end{itemize}

\Cref{tab:week6-calibration-methods} fixes the Week 6 calibration scope. Every record must also identify the reference instrument or resistor, raw artifact, hardware revision, acceptance decision, and corrective action for a failure.

\begin{requirementbox}
Recalibration is required after hardware modifications or sensor replacement.
\end{requirementbox}

Enclosure changes affecting optical contact, airflow, microphone placement, electrodes, or sensor orientation also require recalibration. As of 8 September 2026, methods and record templates exist, but no completed calibration measurement is present.
